# Credits

ship-shape is the auto-updater library the serrebi desktop apps share, from [accessware/ship-shape](https://github.com/accessware/ship-shape) by Quin Gillespie. It checks GitHub Releases for a newer version, shows the update dialogs, downloads and verifies the update, installs it, and relaunches the app.

Third-party projects it uses:

- wxDragon (wxWidgets) for the interface.
- minisign for signature verification before anything is installed (every release asset needs its minisign signature beside it).
- patois for translations.

Questions and bug reports are welcome in the [SerrebiProjects Telegram group](https://t.me/SerrebiProjects). More serrebi projects: [projects.serrebiradio.com](https://projects.serrebiradio.com).
